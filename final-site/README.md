# Ashu Arora — Personal Website V1

A simple, premium, responsive static website for GitHub + Vercel.

## Files
- HTML pages: home, research, projects, writing, teaching, leadership, insights, data-buff, consultancy, about, CV
- `styles.css`: all design and responsive styling
- `profile.jpg`: homepage profile photo
- `documents/cv.pdf`: current detailed 2026 CV

## Easy updates
- Replace `profile.jpg` to change the homepage photo.
- Replace `documents/cv.pdf` to update the downloadable CV.
- Edit the relevant `.html` file to change text.
- Edit `styles.css` to change the visual design.

## Deploy
Upload this folder to a GitHub repository and import the repository into Vercel.
