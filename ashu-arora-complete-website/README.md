# Ashu Arora — Personal Website

Static HTML website, ready for GitHub Pages or Vercel.

## Files
- `index.html` — homepage
- `research.html` — research and publications
- `experience.html` — experience timeline
- `projects.html` — projects index
- `who-benefits-flow.html` — Who Benefits? scroll-driven data story (plus `who-benefits.html`, `-story`, `-studio` design alternatives)
- `patent-dashboard.html` — interactive WIPO patent dashboard (What Drives Global Patenting Activity?)
- `data-buff.html` — Health Economics Data Finder
- `who-benefits-report.pdf`, `patent-report.pdf`, `data-finder-guide.pdf` — project reports
- `assets/` — portrait, project previews and report covers
- `consultancy.html` — BridgeMinds Lab / consultancy
- `book-a-meeting.html` — contact page
- `cv.pdf` — CV
- `vercel.json` — clean URL configuration

## Contact navigation
The **Get in Touch** navigation link opens Calendly: https://calendly.com/aashuzarora/30-minutes-meeting

## Deploy on GitHub / Vercel
Upload the contents of this folder to the repository root, or set the Vercel Root Directory to this folder if it is nested. Ensure `index.html` and `vercel.json` are in the selected root.

The data pages and PDFs are generated by the pipelines in `../analysis/`; edit the sources there and rebuild rather than editing the generated HTML.
